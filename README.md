# HR Analytics Dashboard | Power BI

## Project Overview

The HR Analytics Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It analyses employee data to understand workforce distribution, attrition, and turnover patterns.

The dashboard helps users explore HR metrics through interactive visualisations and filters.

## Project Objectives

- Analyse employee attrition across departments and job roles.
- Understand attrition patterns across different age groups.
- Compare attrition between employees who work overtime and those who do not.
- Track overall employee headcount and attrition KPIs.
- Enable interactive exploration of workforce data.

## Tools and Technologies

- **Microsoft Power BI** — Dashboard development and visualisation
- **DAX** — Measures, KPI calculations, and calculated columns
- **Power Query** — Data cleaning and transformation
- **Data Modelling** — Organising employee data for analysis

## Dashboard Features

### Key Performance Indicators (KPIs)

- Total Employees: 1,470
- Active Employees: 1,233
- Employees Who Left: 237
- Overall Attrition Rate: 16.12%

### Visualisations

- Employee Attrition by Department
- Employee Attrition by Job Role
- Employee Attrition by Age Group
- Employee Attrition by Overtime
- Employee Attrition Distribution (Yes vs. No)

### Interactive Filters

- Gender
- Department
- Job Role

## Key Insights

- The overall employee attrition rate is approximately 16.12%.
- Research & Development has the highest number of employee departures among the three departments.
- Laboratory Technicians have the highest departure count among the job roles shown.
- The dashboard allows users to compare attrition across age groups and overtime categories.

These findings describe employee departure counts, not attrition rates within each group.

## Dataset

This project uses the IBM HR Analytics Employee Attrition & Performance sample dataset, which contains 1,470 employee records.

**Dataset source:** [IBM HR Analytics Employee Attrition Dataset](https://github.com/IamVasil/IBM-HR-Analytics-Employee-Attrition-Performance/blob/main/WA_Fn-UseC_-HR-Employee-Attrition.csv)

The dataset is sample data and does not represent actual IBM workforce records.

## How to Use

1. Clone or download this repository.
2. Download the Power BI `.pbix` report.
3. Open the report using Microsoft Power BI Desktop.
4. Use the slicers to filter employee data.
5. Explore the charts and KPI cards to analyse attrition patterns.
